Objetivo: desenvolver uma API REST chamada Biblioteca API, utilizando Express e TypeScript, capaz de
cadastrar e consultar livros. A API deverá receber e devolver exclusivamente dados em JSON. O armazenamento
poderá ser feito em memória, utilizando um array, não sendo obrigatório o uso de banco de dados.
